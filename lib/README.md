# Vis'it - Akıllı Şehir Rehberi 🌍

Vis'it, Türkiye'nin 81 ilini kapsayan, kullanıcı etkileşimli ve modern arayüze sahip bir seyahat ve keşif mobil uygulamasıdır.

## 🚀 Özellikler
- **Dinamik Kategoriler:** Tarihi Mekanlar, Müzeler ve Gurme Rotalar.
- **Akıllı Harita:** Nokta atışı harita yönlendirmesi (`geo:` protokolü).
- **Yorum & Puanlama:** Küfür filtreli, akıllı isim sansürlü ve fotoğraflı değerlendirme sistemi.
- **Onay Mekanizması:** Kullanıcıların eklediği yeni mekanlar admin onayından sonra yayına alınır.
- **Firestore Altyapısı:** Bulut tabanlı veri yönetimi.
